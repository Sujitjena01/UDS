Components / Buttons

Buttons

Custom button classes built on top of Bootstrap, prefixed with .btn-tp to avoid collisions. Five semantic variants in solid and outline styles, with large and small sizes.

Solid buttons

Use .btn-tp as the base, then add a variant class.

<button class="btn-tp btn-tp-primary">Primary</button>
<button class="btn-tp btn-tp-secondary">Secondary</button>
<button class="btn-tp btn-tp-warning">Warning</button>
<button class="btn-tp btn-tp-danger">Danger</button>
<button class="btn-tp btn-tp-default">Default</button>

Outline buttons

Same variants, transparent fill. Inverts colours on hover.

<button class="btn-tp btn-tp-outline-primary">Primary</button>
<button class="btn-tp btn-tp-outline-secondary">Secondary</button>
<button class="btn-tp btn-tp-outline-warning">Warning</button>
<button class="btn-tp btn-tp-outline-danger">Danger</button>
<button class="btn-tp btn-tp-outline-default">Default</button>

Note: the outline-default has a dark backdrop above for legibility — Neon is very light.

Sizes

Add .btn-tp-lg for large or .btn-tp-sm for small. Omit for the default size.

SM

<!-- Large -->
<button class="btn-tp btn-tp-lg btn-tp-primary">Large primary</button>

<!-- Default -->
<button class="btn-tp btn-tp-primary">Default primary</button>

<!-- Small -->
<button class="btn-tp btn-tp-sm btn-tp-primary">Small primary</button>

States

Disabled buttons drop to 65% opacity and ignore pointer events.

<button class="btn-tp btn-tp-primary" disabled>Disabled</button>
